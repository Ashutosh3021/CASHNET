# Synthetic bank transaction data

All financial transactions generated by this module are synthetic and are intended exclusively for development, testing, demonstration and model evaluation.

`generate_bank_transactions.py` first creates a reusable masked account registry, then creates transaction-graph edges between those same accounts. The original `bank_transaction_data` schema is unchanged. `account_references` and `scenario_metadata` sit alongside it for fund-flow analytics and ground truth.

```powershell
python scripts/banking/generate_bank_transactions.py --transactions 10000 --fraud-rate 0.10 --days 90 --seed 42 --csv
python scripts/banking/generate_bank_transactions.py --validate
```

Outputs under `data/synthetic/bank/` include the transaction dataset, account registry, graph edge list, ATM cash-out references, and optional CSV. Fraud scenarios cover mule, multi-hop, many-to-one, one-to-many, rapid transfer, geographically unusual, and structured-layering flows. The data can be normalized alongside a future authorized source without changing downstream CASHNET processing.
