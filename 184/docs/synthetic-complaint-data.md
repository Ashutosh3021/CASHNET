# Synthetic complaint data

All complaints, persons, contact information, account information, transactions and investigative labels generated by this module are synthetic and are intended exclusively for development, testing, demonstration and model evaluation.

Run `python scripts/complaints/generate_bm_c.py --complaints 1000 --days 90 --seed 42`, then use `--validate`. Records preserve the `BM_C.json` structure and add provenance, synthetic ground truth, bank-registry account IDs, and optional ATM/crypto links alongside it. All contact addresses use impossible zero-prefixed phone numbers or `.invalid` domains. Bank IDs resolve against the separate synthetic bank account registry, so the records can be joined into CASHNET's fund-flow graph.
