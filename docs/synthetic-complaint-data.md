# Synthetic complaint data

All complaints, persons, contact information, account information, transactions and investigative labels generated by this module are synthetic and are intended exclusively for development, testing, demonstration and model evaluation.

Run `python scripts/complaints/generate_complaints.py --complaints 10000 --days 90 --seed 42`, then use `python scripts/complaints/validate_complaints.py`. The strict output is `data/synthetic/complaints/complaint.json`: every entry uses exactly the legacy complaint schema. Provenance, synthetic ground truth, bank-registry account IDs, ATM links, and crypto links are in `complaint_metadata.json`, preserving schema compatibility. All contact addresses use impossible zero-prefixed phone numbers or `.invalid` domains. Bank IDs resolve against the separate synthetic bank account registry, so the records can be joined into CASHNET's fund-flow graph.
